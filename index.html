Guide

Use each format where it belongs

WebP is ideal for photographs and most website graphics. SVG remains the best choice for true vector logos and icons. Large PNG photographs usually waste bandwidth.

Hero images: do not lazy-load the most important image above the fold.

Page images: use loading="lazy" for content further down the page.

Dimensions: include width and height to reduce layout shift.

Responsive files: let the browser choose the smallest suitable source.
